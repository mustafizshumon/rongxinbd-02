# RONGXIN International Trading Company Limited

## V02 – Render fix
All website files are in this single folder. There is no assets directory.

### Run
1. Extract this ZIP.
2. Start your local HTTP server with this folder as its document root.
3. Open the exact localhost address and port shown by the server.
4. Refresh the page.

### Important
The browser runtime is local. Product/hero photographs still use external Unsplash image URLs and therefore require internet access.
The inquiry form is a front-end demo and requires the verified company email to be configured in `app.js` before it can send an email.

### GitHub Pages
Upload the contents of this folder directly to the repository root. `index.html` must be at the root.
